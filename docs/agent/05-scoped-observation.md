# 按范围观察页面

主 Agent 决定范围；观察工具负责过滤与去重，无额外决策节点。

- `page.inspect({scope: "overview"})` 默认返回可见主要入口，不展开目录条目或正文。
- scope 为可见组件 ID 时返回该区域的可见内容。目录条目标题直接合并在 components 中，避免重复列表。
- `ui.actAndObserve` 接受 observe 对象，复用相同参数。滚动、输入默认观察目标；导航默认概览以展示新的入口。
- 不发送坐标；鼠标执行时实时解析位置。允许动作按 actionSets 共享。
- 返回分页默认 40 个组件、最多 100 个；truncated 和 nextOffset 明确表明未返回完。分页不滚动页面，页面滚动仍由 Agent 发起动作。
- notices 额外包含可见的 role=alert/dialog 提示；未标记这些角色的提示尚需 UI 注册才能覆盖。
- 观察使用视口及祖先滚动裁剪范围过滤。当前还不提供任意视觉遮挡或图片识别。

业务数据仍由原数据层管理；DOM 只用于当前渲染范围和动作定位。迁移 Canvas 时替换观察/定位适配器即可；模型收到的结果均为可序列化对象。
