# 主循环变量上下文（试行）

用户原始请求保持不变。当前目标 goal、任务标题 title、计划 plan、进度 progress 作为任务变量直接注入，每轮 Agent 可通过结构化输出更新；字段省略时保持原值。

history 只保留工具失败、运行时失败提醒，以及 Agent 提交的失败经验 failureSummaries。成功操作、普通对话、旧页面观察不累积到模型历史。

observations 仅包含上一轮新工具结果，供下一轮处理，处理后清空。仍需使用的事实、未解决问题和当前步骤由 Agent 写入 progress。进度不得包含尚未观察的事实。全部原始请求和响应仍可在运行追踪中查看，不重新注入模型。

此模式不使用历史摘要模型。失败经验会累积，尚未增加容量限制。需通过真实任务评估模型每轮更新 progress 的可靠性。
