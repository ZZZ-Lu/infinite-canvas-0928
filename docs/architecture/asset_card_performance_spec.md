# 资产卡片 (Asset Card) 设计标准与无限画布性能架构

本文档记录了在无限画布（Infinite Canvas）场景下，针对资产卡片（图片/视频生成卡片）的核心设计标准与性能优化方案，作为后续迭代和新增功能的强制性架构参考。

## 一、 核心痛点与架构哲学

在无限画布中，同屏可能存在几十甚至上百张高分辨率卡片。传统的 Web 渲染方式会导致显存（VRAM）瞬间溢出、GPU 复合层（Compositor Layers）爆炸，以及极度的缩放/平移卡顿。

**架构哲学：**
1. **视觉与数据严格解耦**：UI 看到的是降级后的，底层保存的是最高精度的。
2. **意图驱动渲染**：用户不看的、不交互的，坚决不分配 GPU 资源。
3. **极限 LOD (Level of Detail)**：根据缩放比例动态生灭节点和纹理。

## 二、 视频卡片：意图驱动懒挂载 (Lazy Mounting)

**问题**：`<video>` 标签在浏览器底层会强制分配独立的硬件合成层（Hardware Compositor Layer）并维持解码帧缓存。如果在画布中放置大量隐藏或暂停的视频节点，GPU 负担将呈指数级上升，导致帧率断崖式下跌。此外，卡片内的毛玻璃滤镜（`backdrop-blur`）在拖拽重排时开销极大。

**架构标准**：
1. **彻底的 DOM 剥离**：平时视频卡片必须与图片卡片保持完全一致的 DOM 结构（仅展示封面背景 `div` 和静态播放按钮）。
2. **按需挂载**：只有当用户 **鼠标悬停 (`isHovered`)** 或 **点击播放 (`isPlaying`)** 时，才真正向 DOM 树中挂载 `<video>` 标签及进度条控件。
3. **即刻销毁**：当鼠标离开且视频处于暂停状态时，瞬间卸载整个视频 DOM 节点，立即释放 GPU 内存。
4. **禁用重度 CSS 特效**：卡片内部（尤其是覆盖层、按钮背景）**严禁使用 `backdrop-blur`**，必须使用纯色半透明替代（如 `bg-black/50`）。

## 三、 图片卡片：动态分级纹理 (Dynamic LOD)

**问题**：直接渲染 4K 甚至更高分辨率的图片，极易导致显存溢出（OOM）和画布白屏。

**架构标准**：
1. **统一 Canvas 渲染机制**：图片展示层统一收敛至 `<canvas>` (`CardImageCanvas`) 绘制，避免 `<img>` 标签带来的额外重绘。
2. **基于缩放比的动态加载 (LOD)**：
   - `< 200% 缩放`：仅渲染体积极小的轻量缩略图 (`thumbnailUrl` / 2K 代理图)。
   - `>= 200% 缩放`：触发高清探测。
3. **按需加载原图 (Lazy Original Image)**：只有当缩放比超过阈值（如 `scale > 2.0`），并且该卡片进入了屏幕可视区域中心（`isCardIntersectingRectangle` 视口相交检测），且用户静止（`isZooming === false`），才通过平滑的 `opacity` 过渡绘制真正的无损原图 (`originalImageUrl`)。

## 四、 AI 数据流向：视觉与数据的深度解耦

**问题**：由于 UI 渲染层为了性能大量使用了降级图片（缩略图、2K 压缩图），如果在触发“图生图”、“视频生视频”时直接读取 UI 当前呈现的图像，会导致 AI 获得的参考图精度严重受损。

**架构标准**：
1. **最高精度数据驻留**：在卡片的数据模型 (`CardData`) 中，必须永久持有未经任何压缩的原始二进制对象（如 `trueOriginalFileData` 表示超出 4K 的极限原图，`originalFileData` 表示普通原图）。
2. **跳过 UI 直接提取**：在组装 AI 生成请求（如 `handleGenerate` Payload）时，必须直接判断并提取数据层中的 `trueOriginalFileData` > `originalFileData` > `fileData`，彻底无视当前 UI 正在使用哪个级别的代理图。
3. **原则**：**UI 永远只渲染压缩代理，AI 永远只消费纯血原图。**

## 五、 宏观层面的渲染降级 (Nano-LOD)

针对全局画布的操作，当缩放比例极小（例如 `< 0.60`）时，启动“纳米级 LOD (Nano-LOD)”模式：
- 卸载所有卡片的 DOM 节点树（`isDomCardsActive = false`）。
- 由一个全局的底层 Canvas 一次性绘制所有卡片的极简缩略图方块。
- 一旦用户放大，再无缝恢复局部 DOM 节点。
