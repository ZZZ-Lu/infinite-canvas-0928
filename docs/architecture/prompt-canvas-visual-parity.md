# 提示词面板的 Canvas 与原生排版对齐

此前 Canvas 用估算宽度布局操作栏，以字体符号代替 SVG 图标，并自行逐字测量换行。这些近似会造成按钮位置、字重、标签和换行差异。

## 调整

- Canvas 操作栏的透明语义按钮使用与原生版相同的 CSS 排版参数和 Lucide SVG。缓存绘制读取真实排版结果、字体、颜色和 SVG 路径，不再估算控件宽度或用字符替代图标。
- 标签使用原生字号、字重、字距、颜色及内边距；参考图移除按钮恢复到右上角。
- 文字区域通过左右内边距确定宽度，避免固定 446px 与浏览器小数像素边框产生差异。
- `promptTextLayout.ts` 使用短暂的不可见渲染测量元素，按原生 CSS 取得换行和基线，随后移除。每张文字 Canvas 缓存一次当前文本/宽度/字体对应的结果，清晰度或主题颜色更新复用缓存。
- 操作栏按原生内容流定位，避免固定到底部带来的小数像素偏差。省略号判断加入 0.5px 的舍入容差。
- 保留 300ms 清晰度恢复起点及逐帧绘制队列。

## 验证

类型检查、生产构建通过。浏览器中对同一卡片的 Canvas 状态与原生编辑状态归一化测量：文字区域、添加参考图、引用、模型、比例、分辨率、生成按钮的 x/y/宽/高差异均为 0。退出编辑后检查了 Canvas 的实际显示。

此结果是当前深色主题、图片模型样本的布局验证，不代表所有模型、系统字体和缩放下逐像素完全一致。Canvas 与 DOM 的字体抗锯齿仍可能有轻微差异。

## 架构边界

新增状态只在渲染组件的 ref、Canvas 位图和临时测量函数中。DOM 几何只描述屏幕渲染布局，不回写卡片世界坐标或业务模型；原始 AI 输入、项目数据与 JSON 序列化格式不变。业务命令仍调用原回调。未来替换渲染技术时，仅需替换这些排版/绘制适配器。

首次排版增加浏览器测量和少量透明语义节点；测量只在排队的绘制任务中执行，并缓存结果，不在相机每帧移动时执行。

## 切换交接

Canvas 面板及文字位图常驻，进入原生模式仅隐藏并禁用其交互，不销毁。原生模式立即显示 DOM 文字镜像，避免菜单开启时再挂载一个空白文字 Canvas。

离开原生模式时，以提示词、滚动位置、参考图、控件、生成状态和主题构成渲染版本。两块 Canvas 各自在排队绘制成功后确认当前版本；确认齐全后才卸载原生覆盖层。旧版本的完成通知不能替代新版本。交接期间原生覆盖层停止接收输入，滚轮恢复画布行为。

新增状态均为 GenerationCard 内部的临时渲染状态，不持久化、不修改项目模型。300ms 恢复起点和共享分帧绘制队列保持不变。浏览器验证了进入/退出编辑、滚动后退出、打开/关闭模型菜单的路径；覆盖期间两块 Canvas 均保留有效位图，交接结束后恢复 Canvas 显示。

## 悬浮与焦点

面板外层 pointerenter/pointerleave 控制临时悬浮状态。鼠标位于任意面板区域或文本区有输入焦点时显示原生版本；两者都结束后通过上述就绪交接恢复 Canvas。原生文本框在悬浮时即存在，点击由浏览器放置光标，不再把真实指针焦点重置到文本末尾。菜单、文件选择和预览等正在进行的原生交互继续沿用其保护条件。

浏览器验证：悬浮但 BODY 有焦点时为原生；移出且 BODY 有焦点时为 Canvas；移出但 TEXTAREA 保持焦点时仍为原生；点击面板外失焦后回到 Canvas。未改变滚轮的焦点判断或业务数据。
