# 参考图预览的面板高度

提示词面板原先固定使用 getBottomPanelHeight，但内部参考图预览会撑高文字区域，造成图片和底部控件超出背景。

修复后正常文字高度由 getPromptAreaHeight 提供，不依赖 textarea 是否挂载。预览高度取正常文字高度与目标图片高度的较大值；外层面板在基础高度上增加相同差值，因此背景、文字区域和操作栏使用一致的高度来源。

关闭时不立即清空 activePreviewUrl。等图片淡出，再等待 300ms，外层和文字区域同时用 240ms 高度过渡回弹；原有文字区域足够高则不回弹。尺寸信息保留到交接结束，取消预览和回弹计时器在重新打开或卸载时清理，回弹期间保持原生层。已有开启状态不会被迟到的退出回调关闭。

浏览器验证了展开后图片和生成按钮的边界均在面板背景内；类型检查与存储回归测试通过。

这只改变渲染适配层的临时高度和计时器，不新增持久化字段，不回写卡片世界坐标，不修改原始媒体或提示词。DOM 仍用于显示与图片尺寸读取，业务模型和项目序列化格式不变；后续 Canvas/WebGL 迁移仅需替换预览渲染。

大图直接复用导入画布时生成的显示图。根据 sourceCardId（或现有图片 URL 关联）查找来源卡片并读取 imageUrl；没有关联来源卡片时沿用参考图已有 url。不新增预览缓存，不在打开预览时缩图，不修改参考图和原始媒体数据。显示尺寸由实际 img.onload 提供给临时布局状态。
